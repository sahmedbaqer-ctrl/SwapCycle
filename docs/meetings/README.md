# Agile Meeting Records

This folder contains records of the team's Sprint 1 meetings.

## Required Records
- Sprint planning meeting
- At least eight stand-up meetings, with at least two per week
- Sprint retrospective meeting

## Sprint Planning Record
Include the date, attendees, sprint goal, selected user stories,
task breakdown, and agreed responsibilities.

## Stand-up Records
Include the date, attendees, completed work, next planned work,
blockers, and follow-up actions.

## Sprint Retrospective Record
Include what went well, what did not go well, and agreed
improvements for the next sprint.

## File Naming
Use dates to keep records in chronological order:
YYYY-MM-DD-meeting-type.md
