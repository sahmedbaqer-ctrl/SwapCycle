# User Stories

Sprint 1 user stories for SwapCycle. Each core feature is a Jira epic, and each feature owner wrote three stories in the format *As a [user], I want [goal] so that [benefit]*. The stories are the Sprint 2 backlog.

## Accounts
Epic SCRUM-16 · Owner: Sayed Ahmed

| Key | User story |
|---|---|
| SCRUM-44 | As a user, I wish to make a SwapCycle profile since others will have confidence in whom they swap it with and all the listings and swaps made will be under my name. |
| SCRUM-45 | As an authorized user, I want to sign in and recover my password in case I forgot it so that only I could control my books, messages, and interactions. |
| SCRUM-46 | As a user, I need to be able to control what is visible to other swappers on my profile so that they can decide whether they can trust me or not without disclosing any personal information. |

## Completion Confirmation
Epic SCRUM-20 · Owner: Sayed Mohammed

| Key | User story |
|---|---|
| SCRUM-52 | As a user, I need to be able to mark an exchange as complete after handing over my book so that the app records that I have completed my part of the swap. |
| SCRUM-53 | As a user, I need to be able to confirm that I received the book so that the app knows both swappers completed the exchange. |
| SCRUM-54 | As a user, I would have to report a problem rather than confirming completion to handle any problems like getting an incorrect book or even not getting it at all. |

## Direct Exchange
Epic SCRUM-18 · Owner: Sayed Mohammed

| Key | User story |
|---|---|
| SCRUM-49 | As a user, I need to be able to request a direct exchange for a book so that I can arrange a swap with its owner. |
| SCRUM-50 | As a user, I need to be able to propose a scheduled time and meeting place for a direct exchange so that both swappers can agree on when and where to trade books. |
| SCRUM-51 | As a user, I need to be able to review and accept or reject an exchange offer. To ensure that the proposed offer details works for me |

## Feedback / User-Rating
Epic SCRUM-23 · Owner: Kareem

| Key | User story |
|---|---|
| SCRUM-14 | As a user, I want to be able to rate my exchange experience using a 5-star system so others can know how my experience went this particular exchange. |
| SCRUM-47 | As a user, I want the additional option to add comments along with my reviews so I specify the pros and cons of my exchange. |
| SCRUM-48 | As a user, I want the option to report another user in case they ever violate the rules and regulations of the exchange. |

## In-App Communication & Meeting Arrangement
Epic SCRUM-22 · Owner: Yousif

| Key | User story |
|---|---|
| SCRUM-35 | As a user, I want to be able to schedule a meetup with another user so that we can exchange books at a convenient time and place. |
| SCRUM-36 | As a user, I want to be able to message other users in the app so that we can discuss and confirm book swap details. |

## Physical Book Listings
Epic SCRUM-15 · Owner: Sayed Ali

| Key | User story |
|---|---|
| SCRUM-24 | As a user, I want a list of physical book listings that are real and connected to a library database. |
| SCRUM-25 | As a user, I want each book to display its title, author & contributors, publisher, publishing date, genre, International Standard Book Number (ISBN) and number of available copies. |
| SCRUM-26 | As a user, I want to be able to select a book and choose whether I own it or I wish-list it. |
