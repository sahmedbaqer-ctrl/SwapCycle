# Requirements Documentation

This folder contains the preliminary requirements for SwapCycle.

## Documents to Include
- User stories for the core features
- Functional requirements describing system behavior
- Non-functional requirements describing quality expectations

## Core Features Covered
- Reader accounts and profiles
- Book listings
- Wish lists
- Search and filters
- Two-way and three-way exchanges
- Exchange agreement and handover tracking

Each user story should describe the user, their goal, and the
benefit. Acceptance criteria should explain how the team will
verify that the story is satisfied.
